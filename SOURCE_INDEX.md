# Source index

Full Java source for Wolf3 Werewolf plugin. Build with Maven (`mvn clean package`).

Key packages:
- `com.werewolf.game.arena` — Arena, ArenaManager, ScoreboardHelper
- `com.werewolf.game.roles` — all roles
- `com.werewolf.game.gui` — menus including EntertainingSettingsGUI
- `com.werewolf.game.listeners` — events
- `com.werewolf.game.util` — ItemBuilder, MessageUtil, WorldManager

Maps folders: `plugins/Werewolf/World/`, `plugins/Werewolf/maps/`, or `plugins/Werewolf/World/maps/`.
